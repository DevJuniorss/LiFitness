# LiFitness

> **Universidade Federal do Ceará – Campus Quixadá**  
> Curso: Engenharia de Software  
> Projeto Integrado em Engenharia de Software 3  

O **LiFitness** é um aplicativo mobile em desenvolvimento que conecta pessoas que desejam acompanhamento de **personal trainer** nas academias.  
O objetivo é digitalizar e otimizar a interação entre alunos e profissionais, facilitando o acesso a treinos personalizados, acompanhamento de evolução e, futuramente, **integração com nutricionistas**.

---

## 🎯 Objetivo do Projeto

O **LiFitness** tem como propósito entregar uma solução **moderna, intuitiva e eficiente** para:

- 🏋️ **Criar uma ponte digital entre personal trainer e alunos**, facilitando o acompanhamento;  
- 📝 **Cadastrar, planejar e organizar treinos** de forma prática;  
- 🧩 Controlar **divisões de treino** (ABC, ABCDE, etc.);  
- 📈 Registrar evolução física e desempenho;  
- 🔗 **Futuramente**, integrar acompanhamento com **nutricionistas**.

---

## ⚙️ Principais Features

### 🧾 Gestão de Treinos
- 🏋️‍♂️ Exercícios cadastrados digitalmente;  
- 🔁 Registro de **séries, repetições e cargas**;  
- 🎯 Treinos personalizados enviados pelo personal.

### 🗓️ Agenda e Controle de Horários
- ➕ Cadastro de alunos;  
- 🗂️ Organização da divisão de treinos;  
- ✏️ Criação, edição e acompanhamento dos treinos;  
- 📊 Histórico completo com análise de evolução.

### 📘 Registro de Melhorias e Relatórios
- 📏 Registro de medidas corporais;  
- 📆 Relatórios trimestrais, semestrais e anuais;  
- 📤 Exportação de relatórios em **PDF** e **Excel**.

## 🧭 Padrões de Desenvolvimento

Criar uma branch para cada feature implementada.

### 🌿 Padrões de Branch
- ✨ Features → `feature/nome-da-branch-em-ingles`  
- 🐞 Correções → `fix/nome-da-branch-em-ingles`  
- 🔧 Refatoração → `refactor/nome-da-branch-em-ingles`  
- 🎨 Estilo → `style/nome-da-branch-em-ingles`  
- ⚡ Performance → `perf/nome-da-branch-em-ingles`  
- 🧪 Testes → `test/nome-da-branch-em-ingles`  
- ⚙️ Configurações → `chore/nome-da-branch-em-ingles`

### 📝 Padrões de Commit
- Para features:  
  `feat: descrição clara da alteração`  
- Para fixes:  
  `fix: descrição clara do problema corrigido`

### 🔁 Pull Request
Ao finalizar o desenvolvimento, abrir um **pull request** para a branch principal.
